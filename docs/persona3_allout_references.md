# Persona 3 Reload: All-Out Attack source study

The drawing reference is the [ATLUS nine-finisher showcase, December 14, 2023](https://x.com/p_kouhou/status/1735223109249020133), inspected through its [mirrored gallery of original game stills](https://personacentral.com/p3r-aoa/). The official post does not load in the reference crawler. The [ATLUS Reload site](https://p3re.jp/en/) and [SEGA release notes showing the redesigned S.E.E.S. outfits](https://www.sega.jp/topics/detail/231214_3/) are useful for distinguishing uniform details from the poster color treatments. [ATLUS West's Battle BGM & Gameplay Reveal](https://www.youtube.com/watch?v=3wcKA9nqyY0) is a gameplay reference; the studio showcase stills, not frame-by-frame analysis of this video, drove the portraits.

The pictured poses, relative palette and major compositional landmarks are
observations. Gestures between the rush and held pose, dither, screen-print
arcs, exact framing and original or abbreviated signature copy are terminal
adaptations. No video, bitmap frames, faces, or game font assets are bundled.
All plates use individual pigment values on a 2×4 microgrid per character;
the terminal keeps its existing font size and the renderer packs those values
into single-column Braille glyphs.
